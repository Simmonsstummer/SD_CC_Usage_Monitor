# Support — Claude Code Monitor

## Before opening an issue

**The key shows "No auth"**  
→ Claude Code is not installed or you haven't signed in yet. Run `claude` in a terminal to authenticate.

**The key shows "Auth err"**  
→ Your session token has expired. Run `claude` in a terminal — Claude Code will refresh it automatically.

**The key shows "Net err"**  
→ Your machine couldn't reach `api.anthropic.com`. Check your internet connection or firewall settings.

**The key shows "--" for the countdown**  
→ The plugin is still waiting for its first API response (up to 5 minutes). Press the key to force an immediate refresh.

**The plugin doesn't appear in Stream Deck**  
→ Make sure you are running Stream Deck software **version 6.0 or later**.

**The percentage looks wrong compared to the Claude website**  
→ The plugin polls every 5 minutes. Press the key to force a refresh and get the latest value.
